# FoodGo

O FoodGo é um sistema de delivery desenvolvido em Python utilizando Flask. O projeto foi criado com o objetivo de colocar em prática conhecimentos de desenvolvimento web, banco de dados e controle de usuários.

## Funcionalidades

- Cadastro e login de usuários;
- Gerenciamento de produtos;
- Carrinho de compras;
- Sistema de pedidos;
- Controle de acesso para clientes, funcionários e administradores.

## Tecnologias Utilizadas

- Python
- Flask
- HTML
- CSS
- SQLite

## Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/cayoC-Dev/startup_IA.git
```

2. Entre na pasta do projeto:

```bash
cd startup_IA
```

3. Instale as dependências:

```bash
pip install flask flask-sqlalchemy flask-login
```

4. Execute a aplicação:

```bash
python app.py
```

5. Abra o navegador e acesse:

```
http://127.0.0.1:5000
```
